# Betty Wen Engineering Portfolio

Mechanical engineering portfolio featuring Betty Wen's work in mechanical design, mechatronics, automotive R&D, robotics, simulation, prototyping, and research.

## Portfolio sections

- Experience: Tetrabot, Litens Automotive Group, and Yuwell Medical Devices
- Projects and research: VLA-based robotic tasks and NUS multiphase-flow research
- Engineering capabilities and software
- Embedded résumé with PDF download

## Local development

```bash
npm ci
npm run dev
```

## GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` builds and publishes the static portfolio automatically whenever `main` is updated.
